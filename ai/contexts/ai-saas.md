# INDUSTRY CONTEXT: AI & Deep Tech SaaS

This product serves developers, technical founders, and forward-thinking operators.

The interface must communicate:
- state-of-the-art technology
- high speed and efficiency
- security and reliability
- developer-centric utility
- clean logic

Avoid:
- cartoonish vector illustrations
- default tech templates (Bootstrap-style buttons, basic layouts)
- excessive unnecessary animations that slow down interaction

The experience should feel closer to:
- modern SaaS leaders (e.g., Linear, Vercel, Resend, Supabase)
- high-performance command line tools (TUI-inspired interfaces)
- professional development environments

Design guidelines:
1. **Dark mode by default**: Refined near-blacks (`#080808`, `#0e0e0e`), subtle grid patterns, glowing neon or monochrome accents.
2. **Command interfaces**: Integrated command menus (CMD+K), keyboard shortcut indicators, high focus on interactive keyboard speed.
3. **Data density & status**: High-density layouts, real-time logs, ping indicators, clean dashboard tables with micro-states (success, warning, error).

Users should feel:
"This is a fast, robust, and modern tool built by developers for developers."
