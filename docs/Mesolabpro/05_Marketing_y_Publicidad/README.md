# 05 — Marketing y Publicidad

Módulo de adquisición de tráfico, gestión de pauta digital y activos creativos para Meta Ads (Facebook/Instagram) y TikTok.

## Subcarpetas
- **01_Campanas_Meta_Ads**:
  - Matriz de pruebas de audiencias y creativos.
  - Reglas automáticas para pausar anuncios con CPA no rentable.
- **02_Creativos_y_Videos**:
  - Videos en formato vertical 9:16 para Reels/TikTok.
  - Imágenes estáticas en 1:1 y 4:5 para feed y carruseles.
  - Hooks visuales de los primeros 3 segundos.
- **03_Copywriting_y_Angulos_de_Venta**:
  - Ángulos emocionales (inseguridad con vellos, dolor de la cera, ahorro frente a sesiones láser en clínica).
  - Ángulos lógicos (999.000 pulsos para 10 años, sensor de piel, pago contra entrega).
- **04_Influencers_y_UGC**:
  - Contratos y acuerdos de contenido patrocinado.
  - Guiones de grabación para testimonios de clientes reales.
