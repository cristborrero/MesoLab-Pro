# 07 — Legal y Cumplimiento

Módulo para blindar jurídicamente la operación de MesoLab Pro en Colombia.

## Subcarpetas
- **01_Terminos_Condiciones_y_Politicas**:
  - Políticas de Privacidad y Tratamiento de Datos Personales (Ley 1581 de 2012).
  - Términos y Condiciones del servicio y compras web.
  - Política de Devoluciones y Derecho de Retracto (Ley 1480 de 2011).
- **02_Registro_de_Marca_y_RUT**:
  - RUT vigente con actividades comerciales pertinentes (Comercio al por menor por internet).
  - Registro de marca ante la Superintendencia de Industria y Comercio (SIC).
- **03_Certificaciones_y_Registros_INVIMA**:
  - Registros sanitarios de productos cosméticos o notificaciones sanitarias obligatorias (NSO).
  - Certificados de conformidad para equipos electrónicos.
