# 03 — Ventas y Atención al Cliente

Módulo operativo de contacto directo con el consumidor final, confirmación de pedidos contra entrega y servicio postventa.

## Subcarpetas
- **01_Scripts_WhatsApp_Confirmacion**: 
  - Guión de bienvenida y verificación de dirección completa (con barrio y referencias).
  - Guión de validación de pago en efectivo disponible el día de la entrega.
  - Manejo de objeciones frecuentes.
- **02_Registro_Pedidos_COD**: Hoja de cálculo con todos los pedidos entrantes clasificados por estado (Pendiente, Confirmado, Despachado, Entregado, Cancelado).
- **03_Gestion_de_Garantias_y_Reclamos**: Formulario de recepción de garantías por defectos de fábrica (12 meses en aparatología).
- **04_Plantillas_Mensajes_Seguimiento**: Mensajes automatizados o manuales durante el tránsito del paquete.
