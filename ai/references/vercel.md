# DESIGN REFERENCE: Vercel Style

Vercel represents geometric precision, high-speed loading, and clean developer aesthetics. It features monochrome color schemes, strict borders, and minimal layouts.

---

## KEY STYLISTIC ATTRIBUTES

### 1. Palette & Contrast
- Strict monochrome palette: black (`#000`), white (`#fff`), and clean neutral shades of gray (e.g., `#eaeaea`, `#888`, `#111`).
- Accents are rare and high-contrast (e.g., solid red for errors, bright blue for selected text).

### 2. Geometry & Borders
- Sharp corners (`rounded-none` or tiny `rounded-md`) and strict grid alignment.
- Interfaces are divided by thin, high-contrast border lines rather than shadows.
- Modals and tabs have a flat, solid look.

### 3. Typography
- Bold, dense sans-serif headlines (e.g., Geist Sans, Inter) with tight tracking (`tracking-tight`).
- Code snippets and system readouts use clean, highly legible monospaced fonts (e.g., Geist Mono).

### 4. Interactive Feel
- Tab bars use slide-highlights on hover.
- Flat buttons that fill with solid color on hover or invert contrast.
- Extremely fast transitions that feel snappy and clean.
