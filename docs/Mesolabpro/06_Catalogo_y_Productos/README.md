# 06 — Catálogo y Productos

Módulo de gestión del portafolio comercial, análisis de productos ganadores y fichas técnicas.

## Subcarpetas
- **01_Fichas_Tecnicas_Productos**: Documentos descargables con especificaciones técnicas, modo de uso, contraindicaciones y preguntas frecuentes por SKU.
- **02_Estudios_de_Mercado_y_Ganadores**:
  - Matriz de validación de productos ganadores.
  - Análisis de demanda, saturación de mercado y cálculo de margen > $50.000 COP netos por unidad.
- **03_Material_Grafico_Empaques_Manuales**:
  - Manuales de usuario traducidos y maquetados con la marca MesoLab Pro.
  - Etiquetas, sellos de garantía y folletos de agradecimiento post-compra.
