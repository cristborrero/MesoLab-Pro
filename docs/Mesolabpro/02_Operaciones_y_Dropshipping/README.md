# 02 — Operaciones y Dropshipping

Módulo crítico para el control de la cadena de suministro con Dropi, despacho de pedidos y gestión logística en Colombia.

## Subcarpetas y Protocolos
- **01_Proveedores_Dropi**: Registro de proveedores verificados, tiempos promedio de empaque y teléfonos de contacto de bodegas.
- **02_Gestion_de_Inventario_y_Stock**: Monitoreo de stock activo en Dropi (> 100 unidades por variante).
- **03_Guias_y_Transportadoras**: Control de transportadoras asignadas (Coordinadora, Envía, Interrapidísimo, TCC) y tarifas de flete promedio ($15.000 - $22.000 COP).
- **04_Control_de_Novedades_y_Devoluciones**: Tabla diaria de novedades en reparto:
  - Destinatario ausente.
  - Dirección errada / no encontrada.
  - Teléfono no responde.
  - Reprogramación de entrega para salvar el flete.
